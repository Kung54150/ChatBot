# ChatBot
## รายงานเคสจาก LINE → ระบบรายงาน (OPD1)

- ข้อความในกลุ่ม LINE ของ OPD1 ที่มีแท็ก `#รายงานเคส` หรือมีค่า V/S ตั้งแต่ 2 ค่า (เช่น `BP 90/60 P 120`) บอทจะแยก ชื่อผู้ป่วย อายุ HN เวลา แพทย์ V/S (BP PR RR T O2 sat O2) เหตุการณ์ และการแก้ไข แล้วบันทึกเป็นร่างเคสลงชีต `เคสจาก LINE` ในไฟล์ของระบบ daily-report และตอบยืนยันในกลุ่ม
- เวลา: ใช้ค่าที่พิมพ์ว่า "เวลา 14.30" ถ้าไม่มี ใช้เวลาที่ส่งข้อความ · ผู้รายงาน: ชื่อ LINE ของคนส่ง
- Reply ต่อข้อความอื่นไม่นับเป็นเคสใหม่ (ยกเว้นมีแท็ก `#รายงานเคส`)
- ตั้งค่า Script properties: `REPORT_SHEET_ID` = รหัสไฟล์ Google Sheets ของ daily-report (บัญชีที่ deploy บอทต้องแก้ไขไฟล์นั้นได้) และ `CASE_CHAT` = รหัสกลุ่ม LINE ของ OPD1
- ทดสอบตัวแยกข้อความ: รัน `testCaseParse()` แล้วดู Log

ตัวอย่างข้อความ:
```
#รายงานเคส
ชื่อ นายสมชาย ใจดี อายุ 67 HN 123456
เวลา 14.30
V/S T 38.5 P 120 R 28 BP 90/60 O2sat 89% on cannula 3 LPM
เหตุการณ์: ผู้ป่วยหอบเหนื่อย ซึมลง
แก้ไข: รายงานแพทย์ ให้ O2 เจาะ DTX
```

## เช็คลิสต์ประจำวัน

- ทุกวันบอทส่งการ์ดเช็คลิสต์เข้ากลุ่ม LINE ตามเวลาเข้าเวร: 06:00 น. = NA1, 07:00 น. = NA2-NA4 ให้กดติ๊กรายการที่ทำแล้ว
- เริ่มส่งตั้งแต่ 1 พ.ย. 2569 (ค่า `CHECKLIST_START` ใน `Code.gs`) ก่อนหน้านั้น trigger รายวันจะไม่ส่ง แต่รัน `dailyChecklist()` เองเพื่อทดสอบได้
- ผลการติ๊กบันทึกลงชีต `ChecklistLog` โดยบอทไม่ตอบในกลุ่ม (ไม่แจ้งเตือนซ้ำ) พิมพ์ "เช็คลิสต์" ในกลุ่มเพื่อดูสถานะวันนี้
- ตั้งค่า: Script property `CHECKLIST_CHAT` = รหัสกลุ่ม LINE (ถ้าไม่ตั้ง ใช้ `ALLOWED_CHATS` ตัวแรก)
- แก้รายการที่ `CHECKLIST` ใน `Code.gs` แล้วรัน `setup()` (หรือ `setupChecklistTrigger()`) หนึ่งครั้งเพื่อตั้งเวลา
